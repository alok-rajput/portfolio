IIT Guwahati Research Internship

Worked on speech and audio signal processing using deep learning techniques for mental state classification applications.

  • Developed a BiGRU based deep learning model for classifying speech into stressed, depressed and normal categories.
  • Implemented MFCC feature extraction, silence trimming and noise augmentation techniques for robust audio preprocessing.
  • Trained and evaluated deep learning models using Python, Librosa and TensorFlow based frameworks.
  • Achieved around 88% validation accuracy for speech mental state detection applications.
