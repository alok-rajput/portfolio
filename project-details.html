Underwater Image Enhancement and Object Detection for Maritime Surveillance

This project focuses on improving underwater visibility and enhancing maritime object detection using Artificial Intelligence and image processing techniques.

Underwater images usually suffer from low visibility, color distortion, scattering, and blur because of water absorption and backscatter effects. To solve this problem, a Virtual Polarizer based enhancement technique was developed to restore image clarity and improve visual quality.

After enhancement, the improved images were passed through an enhanced YOLOv11 based object detection system for identifying underwater objects such as divers, fish, and coral structures with higher accuracy.

Key Features

  • Virtual Polarizer based underwater image enhancement
  • Improved visibility and color restoration
  • Enhanced YOLOv11 based maritime object detection
  • Detection of underwater objects with better accuracy
  • Real-time maritime surveillance applications

Technologies Used

  • Python
  • Deep Learning
  • Computer Vision
  • YOLOv11
  • OpenCV
  • Signal & Image Processing
